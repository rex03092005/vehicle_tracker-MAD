# 🚗 AutoCare Premium - Vehicle Tracker

AutoCare Premium is a Flutter-based vehicle management application that helps users organize and track all essential information related to their vehicles in one place. The app provides features for vehicle management, fuel tracking, maintenance reminders, document storage, analytics, and nearby service center information.

## ✨ Features

- 🚘 Add and manage multiple vehicles
- ⛽ Track fuel expenses and mileage
- 🔔 Maintenance and service reminders
- 📄 Store important vehicle documents
- 📊 View vehicle analytics and statistics
- 🛠️ Service center information
- 🌙 Light & Dark theme support
- 💾 Local data storage using Hive and SharedPreferences
- 🎨 Modern Material Design UI

## 🚀 Getting Started

### Prerequisites

- Flutter SDK (3.x or later)
- Dart SDK
- Android Studio or VS Code
- Android Emulator or Physical Device

### Installation

1. Clone the repository

```bash
git clone https://github.com/rex03092005/AutoCare-Premium-Vehicle-Tracker.git
cd AutoCare-Premium-Vehicle-Tracker
```

2. Navigate to the project

```bash
cd vehicle_tracker
```

3. Install dependencies

```bash
flutter pub get
```

4. Run the application

```bash
flutter run
```
